# Carbon Emission Prediction Project

## What is this project about

The goal is to predict a person's or household's **carbon emission score** from lifestyle information. The project uses machine learning regression because the output, CarbonEmission, is a number rather than a category.

For example, the data includes transport method, vehicle distance, diet, air-travel frequency, energy source, shopping habits, waste, recycling, and screen time. The model learns how these inputs relate to carbon emissions.

## Problem statement

Build and compare machine learning regression models that predict CarbonEmission from household and lifestyle features. Then identify the most influential features and use the findings to suggest practical ways to reduce emissions.

## What the notebook does

### 1. Loads and checks the data

The notebook displays the first rows, the data types, missing values, and unique values. The raw dataset has no missing values, but it still needs preparation for machine learning.

### 2. Explores the data

The notebook draws a carbon-emission distribution chart and compares average emissions by transport, diet, heating source, air travel, and energy efficiency.

Use this section to answer questions such as:

- Which transport type has the highest average emission?
- Does frequent air travel have higher emissions?
- Which heating source appears to have higher emissions?

### 3. Prepares the dataset

Machine-learning models need numeric inputs. The notebook:

- Changes blank Vehicle Type values to No vehicle.
- Splits Recycling into columns such as Recycling_Paper and Recycling_Glass.
- Splits Cooking_With into columns such as Cooking_Stove and Cooking_Oven.
- Converts normal categories, such as Diet and Transport, into 0/1 columns using one-hot encoding.
- Saves the result as Carbon Emission - LMS Model Ready.csv.

Do not delete outliers automatically. First inspect them, explain why they might be unusual, and only remove them if your teacher or project requirement supports that decision.

### 4. Splits data for fair testing

The notebook uses 80% of records for training and 20% for testing. The test data is kept aside so we can check whether the model works on unseen records.

### 5. Trains three models

| Model | Why it is included |
| --- | --- |
| Ridge Regression | A simple linear baseline model. |
| Linear Regression | The simplest baseline model for comparison. |
| Ridge Regression | A regularized linear model. |
| Random Forest | Can learn complex, non-linear patterns. |
| Gradient Boosting | Often performs well on structured tabular data. |

### 6. Compares model performance

The notebook uses three measurements:

| Metric | Meaning | Better result |
| --- | --- | --- |
| MAE | Average absolute prediction error. | Lower |
| RMSE | Gives more weight to large errors. | Lower |
| R-squared | How much variation in emissions the model explains. | Higher |

Choose the model with the **lowest RMSE**. The notebook selects it automatically.

### 7. Explains important features

The final chart shows the top features used by the best model. Use it to discuss which lifestyle factors were most useful for predicting emissions.

Important: feature importance shows an association in this dataset. It does **not** prove that one behaviour directly causes higher or lower emissions.

## What to write in the final report

Use this simple structure:

1. **Introduction**  
   Explain that the aim is to predict carbon emissions from lifestyle and household behaviour.

2. **Dataset description**  
   State that the original dataset contains 10,000 rows and 20 columns. CarbonEmission is the target variable.

3. **Data preprocessing**  
   Explain the handling of blank vehicle types, multi-value columns, and one-hot encoding. Mention that no missing values were found.

4. **Exploratory analysis**  
   Include 2 or 3 charts and explain the patterns you observe.

5. **Models used**  
   Describe Linear Regression, Ridge Regression, Random Forest, and Gradient Boosting.

6. **Model evaluation**  
   Include the notebook's comparison table. State which model had the lowest RMSE and why it was selected.

7. **Feature importance and recommendations**  
   Discuss the most important features. Give recommendations supported by the results, such as reducing private-vehicle travel, using cleaner energy, flying less often, or improving household energy efficiency.

8. **Conclusion and limitations**  
   Summarize the best model. Mention that this is an observational dataset, so importance does not establish cause and effect.

- Do not compare models with different train/test splits.
